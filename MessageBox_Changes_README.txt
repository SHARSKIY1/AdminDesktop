Изменения для обработки ошибок загрузки данных

1. В AdminDesktop.csproj добавлен NuGet-пакет MessageBox.Avalonia версии 12.0.0.
   Он совместим с текущей версией Avalonia 12.1.2 в проекте. Более новая версия
   MessageBox.Avalonia 12.1.0 требует Avalonia 12.1.4 или выше, поэтому версии
   Avalonia в проекте не обновлялись.

2. Добавлен Controls/General/MessageBoxService.cs — общий сервис показа ошибок.
3. UserCatalog теперь загружает пользователей асинхронно; при ошибке показывает
   MessageBox и оставляет список UserCard пустым. Пустая таблица вызывает отдельное
   информационное сообщение.
4. GameCatalog работает аналогично для GameCard.
5. StatisticsContent загружает статистику асинхронно; при ошибке показывает
   MessageBox и оставляет демонстрационные значения на графиках. Если база доступна,
   но таблицы пока не содержат регистраций и тегов, появляется информационное окно.
6. Из Program.Main удалена проверка подключения к БД до запуска Avalonia. Это важно,
   чтобы приложение могло открыть окно, а ошибку подключения показать на странице,
   где запрашиваются данные.

Установка:
- Распакуйте содержимое архива в корень репозитория с заменой файлов.
- Не удаляйте .git.
- Из корня решения выполните: dotnet restore
- Затем: dotnet build AdminDesktop.slnx

Новый пакет уже прописан в AdminDesktop.csproj, отдельно устанавливать его командой
'dotnet add package' не нужно. Если захотите установить вручную, используйте:
'dotnet add AdminDesktop/AdminDesktop.csproj package MessageBox.Avalonia --version 12.0.0'

Примечание: сборка в среде подготовки не запускалась, так как .NET SDK там отсутствует.
Проверить сборку нужно локально командой dotnet build.
